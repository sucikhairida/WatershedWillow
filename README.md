# WatershedWillow

WatershedWillow is a Distributed Data Processing Engine that enables Scalable, real-time data processing and auto-scaling architecture.

WatershedWillow is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/WatershedWillow.git`
2. `cd WatershedWillow`
3. Install in editable mode: `pip install -e .`

## Configuration

WatershedWillow is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
